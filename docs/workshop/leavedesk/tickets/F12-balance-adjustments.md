# F12 · HR balance adjustments and history

| Jira field | Value |
|---|---|
| Summary | As HR I want to correct a balance and see the history of every balance |
| Issue type | Story |
| Reporter | Hoa Nguyen (HR) |
| Batch | Spare |

## Description

Sometimes I need to correct a balance: someone came back early from leave, a
compensatory day for working on a Saturday (CR-001), a mistake.

I want to add or remove days for a person and a leave type with a reason, and
see the full history of a balance (every change: who, when, why). Employees
should see the history of their own balance too, without HR's internal notes.
