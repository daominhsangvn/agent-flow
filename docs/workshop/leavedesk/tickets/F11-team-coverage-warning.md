# F11 · Team coverage warning

| Jira field | Value |
|---|---|
| Summary | As a manager I want to be warned when too many people of my team are off on the same day |
| Issue type | Story |
| Reporter | Lan Vo (Sales) |
| Batch | Spare |

## Description

Policy §9: at most 30 % of a team off on the same day. In December everybody
wants the same days.

I don't want the system to block people. When someone requests leave on days
where the team is already at the limit, they should see a warning, and when I
approve such a request I should see it too and write a reason.
