# F07 · Notifications in the app

| Jira field | Value |
|---|---|
| Summary | As a user I want to be notified in LeaveDesk when something happens to a leave request |
| Issue type | Story |
| Reporter | Hoa Nguyen (HR) |
| Batch | Workshop |

## Description

No emails (we decided that). A bell in the top bar with the number of unread
notifications, and a list.

- Managers: when someone in their team requests leave or asks to cancel.
- Employees: when their request is approved, rejected, or the cancellation is
  confirmed.
- HR: when a long unpaid leave needs them.

Clicking a notification should open the request. "Mark all as read" would be
nice.
