---
title: Linear
description: 'Connect Linear to export AgentFlow features to Linear issues'
---

The Linear integration lets you export AgentFlow features to Linear as issues,
keeping your issue tracker in sync with the work planned in AgentFlow.

## Connect

1. In the web app, open **Settings → Integrations → Linear** and start the
   connect flow.
2. Authorize AgentFlow with your Linear workspace.
3. AgentFlow completes the connection and can then export features to Linear.

## Export features

Once connected, export a feature (or set of features) to Linear. AgentFlow
creates the corresponding Linear issues through the `/integrations/linear/export`
endpoint.

## Status

```bash
curl https://api.agentflow.ai/integrations/linear \
  -H "Authorization: Bearer sk_live_YOUR_KEY"
```

The MCP server exposes `get-linear-status`.

## Disconnect

Disconnect from **Settings → Integrations → Linear**, or over the API:

```bash
curl -X DELETE https://api.agentflow.ai/integrations/linear \
  -H "Authorization: Bearer sk_live_YOUR_KEY"
```
